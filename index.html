CSS: estilo para la web

CSS, u hojas de estilo en cascada, define cómo se ven los elementos de una página: sus colores, espacios, tamaños y distribución. Junto con HTML, permite crear interfaces claras y adaptarlas a diferentes pantallas.

Con los selectores elegimos qué elementos cambiar; con las propiedades definimos su apariencia. Si varias reglas coinciden, la cascada y la especificidad determinan cuál se aplica.

¿Qué permite hacer CSS?

Dar personalidad

Elegir colores, tipografías, bordes y espacios para que el contenido sea claro y agradable.

Organizar

Distribuir textos e imágenes con herramientas como Flexbox y Grid.

Adaptar

Cambiar la distribución según el tamaño de la pantalla mediante media queries.

01 / 03 · Fundamentos

Las bases de CSS: cómo se escribe, dónde se incorpora y qué ocurre cuando varias reglas quieren cambiar el mismo elemento.

2.1 Estructura y sintaxis

Una regla CSS tiene un selector, que indica qué elemento se modifica, y una o varias declaraciones formadas por propiedad y valor. Las declaraciones se escriben entre llaves y terminan en punto y coma.

h1 { color: #436f72; }

Ejemplo: esta regla cambia el color de todos los títulos <h1> de la página.

2.2 Tipos de incorporación CSS

Los estilos pueden escribirse dentro del documento HTML (<style>), en un archivo CSS separado (estilos.css) o directamente en un elemento (style="..."). El archivo externo facilita reutilizar los mismos estilos en varias páginas.

Ejemplo: un mismo archivo estilos.css puede dar apariencia coherente a la página de inicio y a la página de contacto.

2.3 Indentación, herencia y comentarios

La indentación ordena el código y facilita su lectura. Algunas propiedades, como color, se heredan de un elemento padre a sus hijos. Los comentarios documentan decisiones y el navegador los ignora.

Ejemplo: si body tiene un color de texto, sus párrafos lo heredan mientras ninguna regla más específica les asigne otro.

2.4 Niveles de especificidad

Cuando varias reglas afectan una propiedad, la especificidad decide cuál gana: en línea > #id > .clase > etiqueta.

Ejemplo: si .titulo da color azul y #principal da color verde al mismo título, prevalece el ID.

02 / 03 · Diseño adaptable

CSS organiza el contenido y permite que una misma página funcione bien en computadores, tabletas y celulares.

2.5 Flexbox, Grid y breakpoints

Flexbox distribuye elementos en una dirección, como una fila de navegación. Grid organiza filas y columnas, como una galería. Los breakpoints son anchos de pantalla en los que el diseño cambia.

Ejemplo: Flexbox alinea los enlaces del menú; Grid coloca seis imágenes en tres columnas.

2.6 Media queries

Una media query aplica reglas CSS solo cuando se cumple una condición, como el ancho de la pantalla. Así se pueden ajustar columnas, tamaños y espacios sin crear páginas diferentes.

@media (max-width: 767px) { ... }

Ejemplo: una zona con dos columnas en computador se convierte en una columna en celular.

03 / 03 · Detalles visuales

Estas herramientas permiten añadir detalles, responder a estados del usuario y controlar qué elemento aparece delante de otro.

2.7 Pseudoelementos

Permiten dar estilo a una parte concreta de un elemento o crear un detalle decorativo con ::before y ::after, sin añadir otra etiqueta HTML.

Ejemplo: colocar una estrella antes del título de una nota.

2.8 Pseudoclases

Seleccionan un elemento según su estado o posición. :hover actúa cuando pasa el cursor; :focus cuando recibe el foco; :first-child selecciona al primer hijo.

Ejemplo: un enlace cambia de color al pasar el cursor sobre él.

2.9 Z-index

Controla el orden de apilamiento de elementos que se superponen. Un valor mayor coloca un elemento por delante.

Ejemplo: un menú desplegable queda visible por encima de la imagen de la página.
